## `province_quarter` — ตัวชี้วัดท่องเที่ยว

| ตัวชี้วัด | ความหมาย | หน่วย | ประเภทที่มี |
|---|---|---|---|
| `visitors` | ผู้เยี่ยมเยือน (ค้างคืนและไม่ค้างคืน) เท่ากับ tourists + excursionists | คน | total, thai, foreign |
| `tourists` | นักท่องเที่ยว (ค้างคืน) | คน | total, thai, foreign |
| `excursionists` | นักทัศนาจร (ไป-กลับ ไม่ค้างคืน) | คน | total, thai, foreign |
| `guest_arrivals` | ผู้เข้าพักแรมในสถานที่พัก | คน | total, thai, foreign |
| `avg_length_of_stay_days` | จำนวนวันพักเฉลี่ย | วัน | total, thai, foreign |
| `avg_expenditure_visitor` / `_tourist` / `_excursionist` | ค่าใช้จ่ายเฉลี่ยต่อคนต่อวัน | บาท/คน/วัน | total, thai, foreign |
| `revenue_visitor` | รายได้จากผู้เยี่ยมเยือน | ล้านบาท | total, thai, foreign |

## ช่วงโควิด (`is_covid`)

ทั้ง `province_quarter` และ `province_month` เก็บข้อมูลครบทุกช่วงเวลา รวมช่วงโควิดด้วย และมีคอลัมน์ **`is_covid`** (True/False) กำกับไว้ ช่วงโควิดใช้ค่า `covid_window` จาก `config/sources.yaml` คือ **2020-03 ถึง 2022-12** ซึ่งเป็นช่วงเดียวกับ `is_covid` ในตาราง `data/core/province_month` ของโปรเจกต์

| ตาราง | `is_covid = True` เมื่อ | จำนวนต่อจังหวัด |
|---|---|---|
| `province_month` | เดือนอยู่ในช่วง 2020-03 ถึง 2022-12 | 34 จาก 84 เดือน |
| `province_quarter` | ไตรมาสมีเดือนใดเดือนหนึ่งอยู่ในช่วงนั้น (รวม 2020-Q1 เพราะมีมีนาคม 2020) | 12 จาก 28 ไตรมาส |

วิธีใช้:
- ใช้ `is_covid` เป็นฟีเจอร์ในโมเดลได้เลย หรือกรองด้วย `df[~df.is_covid]` ถ้าต้องการเฉพาะช่วงปกติ
- ถ้าจะคำนวณ lag หรือค่าเปลี่ยนแปลงจากปีก่อน (YoY) ให้คำนวณบนตารางเต็มช่วงก่อนแล้วค่อยกรอง ไม่อย่างนั้นค่าก่อนหน้าของปี 2023 จะกลายเป็นปี 2019
- lag ของฝนใช้ได้ตามปกติ เพราะฝนไม่ได้รับผลจากโควิด
- ถ้าต้องการช่วงโควิดแบบอื่น ให้แก้ `covid_window` ใน `config/sources.yaml` แล้วรัน `python scripts/clean_domestic_province.py` ใหม่

## การรวมพื้นที่ย่อยเข้าจังหวัด

MOTS แยกชีตบางแหล่งท่องเที่ยวไว้ต่างหาก ทุกชีตเหล่านี้ถูกผูกกับจังหวัดแม่แล้ว:

| จังหวัด | พื้นที่ย่อย |
|---|---|
| ชลบุรี | พัทยา, บางแสน |
| ตราด | เมือง, เกาะช้าง, เกาะกูด, เกาะหมาก |
| สุราษฎร์ธานี | เมือง, เกาะสมุย, เกาะพะงัน, เกาะเต่า |
| นครราชสีมา | ในเมือง, วังน้ำเขียว, ปากช่อง |
| ประจวบคีรีขันธ์ | เมือง, หัวหิน |
| เพชรบุรี | อำเภอเมืองและอื่นๆ, ชะอำ |
| แม่ฮ่องสอน | เมือง, ปาย |

กฎการรวม:
1. ถ้าจังหวัดมีชีตยอดรวมของตัวเอง (เช่น `1.รวมชลบุรี`) จะใช้ค่าจากชีตนั้น ปัจจุบันทุกจังหวัดมีชีตนี้
2. ถ้าไม่มีชีตยอดรวม จะรวมจากพื้นที่ย่อยแทน ตัวชี้วัดที่เป็นจำนวน (คน ห้อง รายได้) ใช้ผลรวม ส่วนค่าเฉลี่ยและอัตราใช้ค่าเฉลี่ยถ่วงน้ำหนัก (ถ่วงด้วยจำนวนคนหรือจำนวนห้อง)
3. ชีต `เมือง+วังน้ำเขียว` เป็นยอดรวมย่อยของ "ในเมือง" กับ "วังน้ำเขียว" จึงไม่นำมาบวกซ้ำ
4. ทุกจังหวัด ทุกไตรมาส ผลรวมพื้นที่ย่อยเท่ากับยอดจังหวัดพอดี ต่างกัน 0 (ดู `subarea_rollup_check.csv`)

ฝนของ HII เป็นระดับจังหวัดอยู่แล้ว (1 แถวต่อจังหวัดต่อเดือน) แต่ใช้กฎเดียวกัน คือถ้าพบแถวย่อยหรือชื่อที่ไม่ใช่จังหวัด จะจับคู่กับจังหวัดแม่ผ่าน crosswalk แล้วรวมให้เหลือ 1 แถว ซึ่งรอบนี้ไม่พบ

## การทดสอบ (`tests/test_province_level_merge.py`)

- แต่ละจังหวัดมีแถวเดียวต่อไตรมาส และแถวเดียวต่อเดือน
- มีครบ 77 จังหวัดตาม `dim_province` และรหัสกับชื่อจังหวัดจับคู่กันแบบหนึ่งต่อหนึ่ง
- ไม่มีชื่อพื้นที่ย่อย (พัทยา บางแสน หัวหิน เกาะ… เมือง… ฯลฯ) และไม่มีคอลัมน์ระดับชีต
- ทุกชีตพื้นที่ย่อยมีจังหวัดแม่ และบางแสนกับพัทยาอยู่ในชลบุรี
- ผลรวมพื้นที่ย่อยเท่ากับยอดจังหวัด และ visitors ของชลบุรีเท่ากับพัทยา + บางแสน ทุกไตรมาส
- ฝนต้นทางมี 1 แถวต่อจังหวัดต่อเดือน ค่าฝนหลัง match ตรงกับต้นทาง และฝนรายไตรมาสเท่ากับผลรวม 3 เดือน
- ทุกแถวมีทั้งข้อมูลท่องเที่ยวและฝน และผลรวมผู้เข้าพักรายเดือนเท่ากับรายไตรมาส
- ข้อมูลช่วงโควิดยังอยู่ครบ `is_covid` เป็นชนิด bool และตรงกับ `covid_window` ทั้งรายเดือนและรายไตรมาส รวมทั้งตรงกับ `is_covid` ใน `data/core/province_month`

## การ clean อื่นๆ

- จับคู่ชื่อชีตกับรหัสจังหวัดผ่าน `config/province_crosswalk.csv` (เช่น `กทม.` → 10, `ประจวบฯ` → 77)
- หาแถวจากชื่อ label ไม่ใช้ตำแหน่งแถวตายตัว จึงรองรับแม่แบบที่ขยับระหว่างปี
- ไฟล์ภาคเหนือปี 2566 ถูกอัปโหลด 2 ครั้ง ค่าตรงกันทุกแถว จึงเก็บไฟล์ล่าสุดไว้ชุดเดียว
- ชีตสรุปรายภาคและระดับประเทศไม่นำมาใช้ เพราะเป็นยอดรวมของหลายจังหวัด

## ข้อควรรู้

- **`visitors` กับ `guest_arrivals` นับคนละแบบ** `guest_arrivals` นับเฉพาะคนที่เข้าพักในที่พัก ค่า `visitors` จึงสูงกว่าเสมอ
- ตัวเลขท่องเที่ยวเป็นยอดรวมทั้งไตรมาส ยกเว้นตัวชี้วัดที่เป็นค่าเฉลี่ยหรืออัตรา
- ช่วง 2020-Q2 ถึง 2021 ตัวเลขต่ำมากเพราะโควิด เป็นค่าจริง ไม่ใช่ข้อมูลผิด (ดูคอลัมน์ `is_covid`)
- ถ้าจะใช้ฝนทำนายจำนวนนักท่องเที่ยวล่วงหน้า ควรใช้ฝนของช่วงก่อนหน้า (lag) แทนฝนของช่วงเดียวกัน
- ข้อมูลปี 2568 (2025) ยังเป็นตัวเลขเบื้องต้น MOTS อาจปรับปรุงภายหลัง
- ไม่ได้ใช้ไฟล์ "สถานการณ์การท่องเที่ยวในประเทศ รายจังหวัด รายเดือน ปี 2568R" เพราะแม่แบบต่างจากชุด Q1-Q4
