# ภาพรวมสำหรับผู้มีส่วนได้ส่วนเสีย

โครงการนี้สร้าง **ชุดข้อมูลจังหวัด-ต่อ-เดือน** สำหรับวิเคราะห์ท่องเที่ยวและฝนในทุก **77** จังหวัดของไทย ภายในช่วงเวลาที่กำหนด

## สิ่งที่เรารวม

| แหล่ง | ให้ข้อมูลอะไร | อยู่ในตารางหลักสำหรับโมเดลหรือไม่ |
|--------|----------------|-----------------------------------|
| **HII** | ฝนเฉลี่ยรายเดือนตามจังหวัด | ใช่ — `avg_rain_mm` ทุกแถวของโครงสร้าง |
| **MOTS** | สถิติท่องเที่ยวจากไฟล์ Excel/PDF ที่เผยแพร่ | บางส่วน — ดูด้านล่าง |
| **NSO** | รอบสำรวจที่พัก (แบบ MD) | ตารางแยกเท่านั้น **ไม่ใช่** อนุกรมท่องเที่ยวรายเดือน |

## ผลลัพธ์หลักสำหรับการสร้างโมเดล

**`province_month.parquet`** เป็นกริดครบ: ทุกจังหวัด × ทุกเดือนในช่วง (**2018-01** ถึง **2025-08**) พร้อมฝน ตัวชี้วัดท่องเที่ยว (ตามที่มี) และธงช่วง COVID

- **`guest_arrivals`** — จากไฟล์รายไตรมาสภายในประเทศของ MOTS
- **`visitors_total`** — จากรายงานรายเดือนระดับจังหวัดของ MOTS โดยทั่วไปตั้งแต่ **2023-01** (ดู [รายงานความครอบคลุม](../coverage_report.md))
- **`is_covid`** — ธงที่โครงการกำหนดสำหรับ **2020-03** ถึง **2022-12** ใช้ทำเครื่องหมายช่วงวิกฤตสำหรับการวิเคราะห์ **ไม่ได้** แปลว่าเป็นการพิสูจน์เหตุและผล

พื้นที่ย่อย (เช่น พัทยา เกาะช้าง) อยู่ในตาราง long แต่ **ไม่** รวมเข้า `province_month`

## สิ่งที่ไปปไลน์นี้ไม่ทำ

- **ไม่** ฝึกหรือ deploy โมเดลทำนาย
- **ไม่** สร้าง lag, ค่าเฉลี่ยเคลื่อนที่ หรือฟีเจอร์ ML
- **ไม่** รับประกันว่าทุกช่องท่องเที่ยวจะมีค่า — ช่องว่างสะท้อนแหล่งที่ยังไม่เผยแพร่หรือ parse ไม่ได้ [รายงานความครอบคลุม](../coverage_report.md) เป็นตัวเลขอ้างอิงหลังแต่ละ build

## คุณภาพและที่มา

การดาวน์โหลดบันทึกใน **`data/manifest/manifest_downloads.csv`** QA สรุป **สถานะล่าสุดต่อ URL** ไฟล์ที่ parse ไม่ได้อยู่ใน **`data/staging/mots/quarantine/`**

สำหรับคำสั่งรันทางเทคนิค ดู [คู่มือผู้ปฏิบัติการ](pipeline_operators.md) สำหรับนิยามตาราง ดู [พจนานุกรมข้อมูล](data_dictionary.md)
