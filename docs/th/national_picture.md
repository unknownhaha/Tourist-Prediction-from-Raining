# ภาพรวมระดับประเทศ

มุมมองรายเดือนจาก **`province_month.parquet`** รวมทุก **77** จังหวัด (2018-01–2025-08 ค.ศ.)

แผนภูมิด้านบนแสดง:

- **Guest arrivals** — ผลรวม `guest_arrivals` ต่อเดือน
- **Visitors** — ผลรวม `visitors_total` ตามที่เผยแพร่ (ช่วงก่อน ~2023 เป็นช่องว่าง ไม่ใช่ศูนย์)
- **ฝน** — ค่าเฉลี่ย `avg_rain_mm` (แกนขวา, มม.)
- **แถบสี** — ช่วง `is_covid` ของโครงการ (2020-03–2022-12) ไม่ได้แปลว่าเป็น causation

ไปปไลน์นี้เตรียมข้อมูลเท่านั้น ไม่ได้ฝึกหรือรันโมเดลทำนาย ดู [พจนานุกรมข้อมูล](data_dictionary.md)
