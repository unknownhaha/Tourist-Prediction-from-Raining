# คู่มือโครงการ

ชุดข้อมูลระดับ **จังหวัด × เดือน** (**2018-01** ถึง **2025-08** ค.ศ.) รวมฝนจาก HII ไฟล์แนบท่องเที่ยว MOTS และข้อมูลสำรวจที่พัก NSO

## เริ่มตามบทบาท

| บทบาท | เริ่มที่ |
|--------|---------|
| ผู้ดูแลไปปไลน์ | [คู่มือผู้ปฏิบัติการ](pipeline_operators.md) |
| วิทยาการข้อมูล / ML | [ภาพรวมระดับประเทศ](national_picture.md) แล้ว [ส่งต่อ DS / ML / QA](handoff_ds_ml_qa.md) |
| QA / นักวิเคราะห์ | [ส่งต่อ](handoff_ds_ml_qa.md) และ [รายงานความครอบคลุม](../coverage_report.md) |
| ผู้มีส่วนได้ส่วนเสีย | [ภาพรวมระดับประเทศ](national_picture.md) (แผนภูมิ) |

## ตัวสำรวจแบบโต้ตอบ

เปิด **`site/index.html`** ในเบราว์เซอร์ แล้วสลับภาษา **EN / ไทย** ที่แถบด้านบน หลังแก้ markdown ให้รัน:

```powershell
python -m src.docs.build_site
```

## อ้างอิงด่วน

- **ตารางเริ่มต้นโมเดล:** `data/core/province_month.parquet`
