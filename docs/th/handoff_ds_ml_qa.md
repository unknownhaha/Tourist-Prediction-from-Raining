# ส่งต่อ: Data Science, ML, QA

## ตารางเริ่มต้น

ใช้ **`data/core/province_month.parquet`**: โครงสร้าง **77 × 92** เต็ม (2018-01–2025-08 ค.ศ.) ฝน HII **`avg_rain_mm`** MOTS **`guest_arrivals`** (รายเดือน จากไฟล์รายไตรมาสภายในประเทศเป็นหลัก) **`visitors_total`** (รายเดือน จากรายงาน `(R)` ของ MOTS โดยทั่วไป 2023-01–2025-08) และ **`is_covid`**

แผ่นพื้นที่ย่อย (พัทยา เกาะช้าง ฯลฯ) **ไม่** รวมในตารางนี้ ยังอยู่ในตาราง long ที่ `area_level = sub_area` และ `province_id` ว่าง

ถ้าจังหวัด-เดือนเดียวกันปรากฏในมากกว่าหนึ่งไฟล์ ไปป์ไลน์เก็บ **ตัวเลขครั้งแรกที่เผยแพร่** คือคอลัมน์ที่ออกรายงานสำหรับปีนั้น ไฟล์ปีถัดไปที่ทวนเดือนเดิมในคอลัมน์ปีก่อน **ไม่** แทนที่ค่านี้ หลังกฎนี้ `conflicts.csv` ว่าง อย่าเฉลี่ยค่าซ้ำ หรือสลับไปใช้ตัวเลขที่แก้ไขทีหลัง เว้นแต่เจ้าของไปป์ไลน์เปลี่ยนกฎ

หน้าต่างโมเดลจบที่ **2025-08** เดือนกันยายน–ธันวาคม 2025 รวมไตรมาส 3 และ 4 ของปี 2025 อยู่ใน `fact_tourism_long` เท่านั้น

## ตารางอื่น

- **`fact_tourism_long`**: ทุก metric ของ MOTS ประเภทนักท่องเที่ยว และแถวรายไตรมาส
- **`fact_tourism_province_month`**: ข้อเท็จจริงรายเดือนระดับจังหวัด (หนึ่งแถวต่อ metric × tourist_type)
- **`fact_accommodation_nso`**: snapshot สำรวจ NSO — อย่าใช้เป็นรายเดือนโดยไม่มีกฎ join ที่อนุมัติ
- **`dim_month` / `dim_province`**: มิติ (`region`, `province_en` บนจังหวัด)

## สำหรับ Data Science, ML และ QA

- ทำนายจาก **`guest_arrivals`** เมื่อต้องการครบช่วง 2018-01–2025-08 จุดที่มีทั้งสองชุด ตัวเลขนี้ตรงกับจำนวนผู้เข้าพักรายเดือน ใช้ **`visitors_total`** เฉพาะตั้งแต่ **2023-01** ช่องก่อนหน้านั้นคือข้อมูลไม่มี ไม่ใช่ศูนย์
- `guest_arrivals` ที่เป็น **0** คือศูนย์ที่ต้นทางเผยแพร่ (27 ช่อง ส่วนใหญ่ 2020-04) ให้คงเป็นศูนย์
- เริ่มโมเดลที่ตาราง **77 จังหวัด** ชีตแหล่งท่องเที่ยว 14 แห่งเป็นแถวสำรวจในตาราง long ไม่ใช่คอลัมน์ของ `province_month`
- **`is_covid`** เป็นป้ายช่วง 2020-03 ถึง 2022-12 ไม่ใช่ข้อสรุปว่าโควิดเป็นสาเหตุ
- อย่านำ **`fact_accommodation_nso`** เข้าตารางรายเดือน จนกว่าจะมีกฎ join และเจ้าของไปป์ไลน์รับกฎนั้น
- **`region`** เป็น 6 ภาคการท่องเที่ยว กรุงเทพคือ `central` แผนที่คนละแบบคือการเปลี่ยน `dim_province`
- **`unmapped_provinces.csv`** แสดงชื่อจังหวัดที่จับคู่ไม่ได้ ไม่แสดงชีตแหล่งท่องเที่ยว ไฟล์ว่างแปลว่าจับคู่จังหวัดครบ

## สำหรับเจ้าของไปป์ไลน์

คุณเป็นเจ้าของกฎเดือนซ้ำ หน้าต่าง 2025-08 การใส่จังหวัดแม่ให้แถวแหล่งท่องเที่ยว การแตกไฟล์ NSO ใหม่ และ `python -m src.ingest.mots_cleanup` บทบาทอื่นต้องได้สำเนา **`data/core/`** จากคุณ เมื่อไฟล์ Parquet นั้นยังไม่อยู่ใน git
